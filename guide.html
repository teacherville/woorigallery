우리 반 전용 서버로 쓰기

공용 주소는 무료 서버라 여러 반이 한꺼번에 쓰면 입장이 막힐 수 있어요. 선생님 구글 계정으로 무료 서버를 하나 만들어 연결하면, 같은 주소에서 우리 반만 쓰는 서버로 바뀌어요.

  • 구글 계정
  • PC에서 약 10분
  • 무료 · 카드 등록 없음

어떻게 연결되나요?

화면은 지금 쓰는 티처빌 주소 그대로예요. 작품을 보관하는 곳(파이어베이스)만 선생님 것으로 바꿔요. 깃허브에 올리거나 코드를 고칠 일은 없어요.

  1. 1~4단계 · 파이어베이스선생님 구글 계정으로 보관 공간을 만들고, 그 주소(설정값)를 복사해요.
  2. 5단계 · 이 페이지복사한 설정값을 이 페이지 입력 칸에 붙여 넣어요. 이 컴퓨터 브라우저가 기억해요.
  3. 6단계 · 우리반 전시회평소처럼 전시회를 만들고 링크·QR을 공유해요. 링크에 선생님 서버 정보가 자동으로 붙어요.
지금 이 기기는 서버에 연결돼 있어요. 전시회로 가기 →

공용 서버에서 만든 전시회는 옮겨지지 않아요. 연결한 뒤 새로 만들어 주세요.
아이들은 선생님이 공유하는 링크·QR이나 6자리 코드로 들어와요.

1파이어베이스 프로젝트 만들기

  1. console.firebase.google.com에 구글 계정으로 들어가요.
  2. 새 Firebase 프로젝트 만들기(처음이라면 Firebase 프로젝트를 설정하여 시작하기)를 누르고 이름을 정해요. 예: our-gallery
  3. Gemini, 구글 애널리틱스 사용 여부를 물으면 모두 꺼도 돼요. 그대로 진행해 만들어요.

  2. 데이터베이스 만들기 → 위치는 싱가포르(asia-southeast1) → 잠금 모드로 시작 → 사용 설정

싱가포르는 한국에서 가장 가까운 위치예요. Realtime Database는 한국 위치를 고를 수 없어요.

규칙을 게시할 때 "누구나 읽을 수 있다"는 경고가 떠도 그대로 게시하면 돼요. 아이들이 로그인 없이 전시회를 봐야 해서 읽기만 열어 둔 규칙이에요.

3익명 로그인 켜기

  1. 왼쪽 메뉴의 보안에 마우스를 올리면 나오는 Authentication을 누르고 시작하기를 눌러요.
  2. 로그인 방법 탭 → 익명 → 사용 설정 → 저장

선생님 기기를 알아보는 데만 쓰여요. 아이디나 비밀번호를 만드는 게 아니에요.

메뉴 이름이나 위치는 파이어베이스 화면 개편에 따라 조금 다를 수 있어요. 메뉴가 안 보이면 왼쪽 위 검색창에 이름을 입력해 찾아 주세요.

4설정값 복사하기

  1. 왼쪽 메뉴의 ⚙ 설정에 마우스를 올리면 나오는 일반을 눌러요.
  2. 아래로 내리면 나오는 내 앱에서 </> 웹 아이콘을 눌러요.
  3. 앱 닉네임을 아무거나 적고 앱 등록을 눌러요. Hosting 체크는 하지 않아요.
  4. 나오는 코드 중 const firebaseConfig = { 부터 }; 까지 복사해요. 코드 전체를 복사해도 괜찮아요.
  5. 복사한 내용은 어디에도 붙여 넣지 말고, 바로 아래 5단계 입력 칸으로 가져와요.

5이 페이지에 붙여 넣고 연결하기

복사한 설정값을 아래에 붙여 넣고 연결 확인하기를 눌러요. 1~4단계가 제대로 됐는지 바로 확인해요. 세 항목에 모두 ✓가 뜨고 연결됐어요가 나오면 성공이에요.

6전시회 만들고 아이들에게 공유하기

  1. 5단계에서 전시회 만들러 가기 →를 눌러요. 우리반 전시회 첫 화면 아래에 "우리 반 전용 서버 사용 중"이 보이면 제대로 연결된 거예요.
  2. 선생님 · 전시회 만들기로 반, 주제, 작품 사진을 넣고 저장해요.
  3. 저장하면 입장 코드, 링크, QR이 나와요. 아이들에게는 링크·QR이나 6자리 코드를 알려 주면 돼요. 링크·QR이 가장 빠르고 확실해요.
  4. 다른 PC나 태블릿에서 전시회를 고치려면, 그 기기에서도 이 페이지 5단계를 한 번 해 주세요. 같은 설정값을 붙여 넣은 뒤 관리 코드로 불러오기를 써요.

막혔을 때

"databaseURL이 없어요"가 떠요

앱을 등록한 뒤에 데이터베이스를 만들면 설정값에서 이 줄이 빠져요. 프로젝트 설정 페이지를 새로고침한 뒤 설정값을 다시 복사해 주세요.

"익명 로그인이 꺼져 있어요"가 떠요

3단계에서 익명 로그인을 사용 설정하고 저장까지 눌렀는지 확인해 주세요.

"규칙이 아직 게시되지 않았어요"가 떠요

2단계 ③에서 규칙을 붙여 넣은 뒤 게시를 눌러야 해요. 기존 내용을 모두 지우고 붙여 넣었는지도 확인해 주세요.

아이들이 코드를 넣으면 "찾지 못했어요"가 떠요

코드를 다시 확인해 주세요. 그래도 안 되면 선생님이 공유한 링크나 QR로 들어오게 해 주세요. 링크·QR은 선생님 서버로 바로 연결돼요.

공용 서버로 돌아가고 싶어요

첫 화면의 공용 서버로 돌아가기를 누르면 연결은 이 기기에 남겨 둔 채 공용 서버로 바뀌어요. 다시 쓰려면 첫 화면의 내 전용 서버로 돌아가기를 한 번 누르면 돼요. 연결을 완전히 지우려면 이 페이지 위쪽의 연결 끊고 공용 서버로 돌아가기를 눌러요. 어느 쪽이든 선생님 서버의 전시회는 그대로 남아 있어요.

알아 두면 좋은 것

  • 무료 요금제로 한 반 수업은 충분해요. 결제 카드를 등록하지 않으면 요금이 나가지 않아요.
  • 전시회와 사진은 선생님 구글 계정의 파이어베이스에 저장돼요. 티처빌은 저장된 내용을 보거나 관리하지 않아요.
  • 아이 이름 대신 번호나 별명을 쓰고, 얼굴이 보이는 사진은 올리지 말아 주세요.
  • 다 쓴 전시회는 ⋯ → 지우기를 누르면 작품과 글이 모두 지워져요. 전시 닫기는 입장만 막아요.
